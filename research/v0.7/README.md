# Temporal Clique Research v0.7 — reproducible checkpoint

Read `RESEARCH_UPDATE_v0.7.md` for scope, evidence states, the two exact K7 schedules, novelty limitations, sources, and commands. Source scripts are in `code/`, captured sample outputs under `logs/`.

This is a supplemental research checkpoint to v0.6, not a replacement for the original six-vertex treewidth-2 obstruction certificate. The key new insight is **pivot-aware sampling**: naive uniformly random orderings almost always fall within known pivotability results at n=7,8, so genuine adversarial tests must concentrate on the non-pivotable cases.

No universal spanner theorem is claimed.
